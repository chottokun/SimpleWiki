# クイックスタートガイド

SimpleWiki を最速で使い始めるためのセットアップ手順です。

## 準備事項

- Windows PowerShell 5.1 または PowerShell 7+
- 特殊なソフトウェアのインストールは不要です（完全オフライン動作用 DLL 同梱済み）。

## 起動手順

1. リポジトリをクローンまたはダウンロードします。
2. `Start-MarkdigWiki.bat` をダブルクリックします。
3. ブラウザが自動起動し、`http://localhost:8080/` にアクセスされます。
