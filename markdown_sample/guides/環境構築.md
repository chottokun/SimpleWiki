# 開発環境構築ガイド

SimpleWiki の開発およびカスタマイズを行うための環境構築ガイドです。

## 依存関係

SimpleWiki は [Markdig](https://github.com/xoofx/markdig) ライブラリを使用して Markdown の変換を行っています。

- `lib/Markdig.dll`
- `lib/mermaid.min.js` (Mermaid ダイアグラム描画用)

## テストの実行方法

Pester ユニットテストを実行するには、以下の PowerShell コマンドを実行します。

```powershell
Invoke-Pester .\tests\Start-MarkdigWiki.Tests.ps1
```
